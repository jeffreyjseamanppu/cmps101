Lecture: Generative AI and Large Language Models

Part 1 — What Is Generative AI?

Artificial intelligence is a broad field focused on building systems that perform tasks associated with intelligence. Machine learning uses data to learn patterns. Generative AI produces new content based on patterns learned during training and information supplied in a prompt.

Classification

Given an email, a system predicts whether it is spam.

Prediction

Given past sales, a system estimates future demand.

Generation

Given a request, a system drafts an email, explanation, image, or code snippet.

Examples: drafting study guides, summarizing documents, generating sample code, brainstorming marketing copy, and creating images. Generated output is not automatically accurate or original in every meaningful sense; it must be reviewed.

Part 2 — How Large Language Models Work

An LLM is a machine learning model trained on large amounts of text and other data to learn statistical relationships among tokens. Many modern LLMs use a transformer architecture, which helps the model use context from the input. During generation, the model calculates probabilities for possible next tokens, selects one, and repeats the process. Additional training and system design help the model follow instructions.

Training data
Examples used to learn patterns during model development.
Token
A unit of text processing, such as a word, part of a word, or punctuation mark.
Neural network
A computational system with learned numerical parameters that transforms input into output.
Transformer
A neural network architecture that uses attention mechanisms to relate information across a sequence.
Inference
Using a trained model to generate an answer to a new prompt.
1. User prompt
“Explain cloud computing to a beginner.”
↓
2. Tokenization

3. Model processing

Important distinction: LLMs can produce convincing explanations without verifying every statement. Some assistants also use tools, such as web search, but those capabilities depend on the product, model, and settings.

Part 4 — Prompt Engineering

A prompt is the input or instruction given to an AI model. Better prompts often include a clear task, relevant context, an intended audience, constraints, and a desired output format.

Prompt formula: Task + Context + Audience + Constraints + Output Format + Verification Requirements.

Basic: “Explain cybersecurity.”

Improved: “Explain cybersecurity to a first-year college student. Include three common threats and real-world examples.”

Advanced: “Act as an introductory computer science instructor. Explain cybersecurity to first-year college students in 250 words or fewer. Define phishing, ransomware, and multifactor authentication. Provide one practical example of each, followed by three review questions. Use clear, nontechnical language.”

Students should not assume longer prompts always produce better results. The goal is useful, specific, testable instructions.

Part 5 — Ethics, Risks, and Limitations

  • Hallucinations: AI can confidently present incorrect or invented facts and citations.
  • Bias: Outputs can reflect imbalances in training data or model behavior.
  • Privacy: Do not paste passwords, personal records, confidential business data, or another person's private information into AI tools.
  • Copyright: AI-generated content can raise questions about ownership, attribution, and use of protected works.
  • Academic integrity: Follow course policies; disclose AI use when required and submit your own analysis.
  • Overreliance: Verify important claims against credible, independent sources.

Discussion Board: Should Students Use Generative AI for College Assignments?

Generative AI can help students brainstorm, explain difficult ideas, and improve writing, but it can also produce errors or replace the learning process if used uncritically.

Initial post (approximately 200 words): Discuss at least two benefits and two risks of AI use in college coursework. Explain where you would draw the line between acceptable assistance and inappropriate substitution for a student's own work. Propose one rule a university should adopt.

Peer responses: Respond to two classmates with at least 75 words each. Build on their reasoning, ask a meaningful question, or respectfully challenge a point with an example.

Homework Assignment: ChatGPT vs. Gemini — Which AI Model Would You Choose?

Purpose: Conduct a hands-on comparison of two generative AI assistants, evaluate their responses using the same criteria, and recommend which one you would use for a specific academic or professional task. This is an evaluation exercise, not a contest to declare one company universally better.

Platforms: ChatGPT and Google Gemini. Use versions accessible to you without purchasing a subscription. Record the model name shown, if available; otherwise record the product and account tier or state “model not displayed.”

Step 1 — Prepare a Fair Test

  1. Open both platforms. Start a new conversation on each platform for each test prompt.
  2. Use the exact same prompt text in both systems, without changing words or adding follow-up instructions.
  3. Use default settings where possible. Do not enable web search or special tools in only one system. If settings or capabilities differ, document that limitation.
  4. Record the date, product, model/version if shown, and any notable settings.
  5. Do not enter private, sensitive, or confidential information.

Step 2 — Run Three Comparison Tests

Copy each prompt exactly into both ChatGPT and Gemini. Save both responses for each test (six responses total).

Test A — Explain a Technical Concept

Explain the difference between artificial intelligence, machine learning, and deep learning to a first-year college student. Use a simple analogy, give one real-world example of each, and conclude with a comparison table. Keep the explanation under 300 words.

Test B — Solve a Practical Problem

A small business with 12 employees wants to improve cybersecurity but has a limited budget. Recommend five practical steps in priority order. For each step, explain why it matters, estimate whether the cost is low, medium, or high, and identify one mistake to avoid. Use plain language.

Test C — Create an Educational Resource

Create a 10-question multiple-choice quiz for an introductory computer science course on cloud computing, databases, cybersecurity, and generative AI. Include four answer choices per question, a separate answer key, and a one-sentence explanation for each correct answer.

Step 3 — Evaluate Both Systems

Score each response from 1 (poor) to 5 (excellent) using the same criteria. Verify at least two factual claims from each platform against reliable independent sources, such as course materials, university resources, official documentation, or reputable publications. Cite those sources.

CriteriaWhat to look for

CompletenessDoes it answer every part of the prompt?
OrganizationIs the structure easy to follow and useful?
Practical usefulnessWould the answer actually help with the stated task?

Step 4 — Decide Which Model You Would Use

Write a 400–600 word analysis that answers all of the following:

  1. Which system performed better on each of the three tasks? Cite specific examples from the responses.
  2. Did either system make a factual error, omit an instruction, or produce an especially useful answer? Explain.
  3. Which system would you choose for learning a new computer science concept, and why?
  4. Which would you choose for solving a practical business problem, and why?
  5. If you could use only one of these systems for your own coursework, which would you choose based on your results? Defend your decision with evidence.
  6. What limitations make your comparison less than perfectly controlled (for example, model version, tool availability, or variability between runs)?
Important: There is no required winner. A thoughtful conclusion may favor ChatGPT, favor Gemini, or find that different tools are better for different tasks. Your grade depends on your evidence and reasoning, not which platform you choose.

Step 5 — Submit Your Work

Submit one PDF or Word document containing:

  1. Your name, course, and assignment title.
  2. Testing date, model/version information, and settings.
  3. The three prompts and all six AI responses (screenshots or pasted text; an appendix is acceptable).
  4. The completed comparison scorecard with short explanations supporting the scores.
  5. At least four independent fact-checks in total: two claims from ChatGPT and two from Gemini, with citations.
  6. Your original 400–600 word recommendation and analysis.
  7. A short disclosure describing how you used AI in completing the assignment.

Submission: Upload to the course learning management system by the deadline announced by your instructor. Students should write their own evaluation and recommendation rather than asking an AI tool to write the analysis for them.
